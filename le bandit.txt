2. Mecánicas base: qué pasa en un spin “normal”
2.1. Super Cascades + Cluster Pays

Formas un cluster ganador (≥5 símbolos conectados).

Super Cascades: no se eliminan solo los símbolos del cluster, se elimina ese tipo de símbolo en todo el grid.

Luego caen nuevos símbolos y pueden encadenar más premios sobre el mismo spin.

Impacto de diseño:

Aumenta la sensación de “spin con historia”: una tirada puede durar varios pasos.

Mejora la percepción de valor: un solo spin puede dar 2–4 pagos sucesivos.

2.2. Golden Squares

Cada vez que un símbolo forma parte de un cluster ganador, el cuadrado detrás de ese símbolo queda marcado como Golden Square. 
Casasdeapuestas.com

Esos cuadrados se quedan latentes y son la base del sistema de premios instantáneos.

2.3. Rainbow Feature (lluvia de premios instantáneos)

Tras terminar todas las cascadas de un spin, si aparece un símbolo Rainbow:

El Rainbow activa todas las Golden Squares del tablero.

Cada Golden Square revela:

Monedas de distintos niveles:

Bronze: ~0,2x – 4x

Silver: ~5x – 20x

Gold: ~25x – 500x

O símbolos especiales:

Four-leaf Clover: multiplica monedas adyacentes (2x, 3x, 4x, 5x o 10x).

Pot of Gold: colector, suma todos los valores de monedas y otros Pots y vuelve a reactivar Golden Squares.

Conclusión: el juego gira en torno a “marcar” el tablero con Golden Squares y luego rezar al Rainbow. El Rainbow es el gatillo de adrenalina.

5. Cómo presentar la gráfica de progreso de premios según tiradas

No tenemos los datos internos de Hacksaw (obviamente), pero para YouTube lo que necesitas es una gráfica didáctica, no forense. Te estructuro cómo montarla para que parezca salida de analítica de producto:

5.1. Qué tipo de gráfica usar

Yo usaría línea de “balance acumulado”:

Eje X: número de tiradas (por ejemplo, 0 a 500 spins).

Eje Y: balance acumulado en múltiplos de apuesta (por ejemplo de -300x a +500x).

Y sobre esa gráfica, tres runs simuladas conceptuales:

Sesión fría (linea roja):

Ligeramente bajista todo el rato, con mini picos de +10x / +20x pero sin bonus fuerte.

Visualiza la realidad de la varianza negativa.

Sesión neutra (línea gris/azul):

Baja al principio, remonta con algún bonus de 80x–120x y termina cerca de -50x / +50x tras 500 spins.

Transmite el efecto del RTP medio.

Sesión caliente (línea verde):

Empieza similar a las otras, pero entre los spins 200–350 conectas:

Un Luck of the Bandit decente (100x–150x).

Un All That Glitters o Treasure al final, que te pega un salto vertical de +400x o +600x.

Narrativa que puedes usar:

“Las tres sesiones tienen el mismo RTP teórico de fondo, pero en la práctica, todo depende de si pillas esos bonus altos. La línea verde es lo que la gente sube a Twitter, las otras dos son lo que le pasa a la mayoría.”

5.2. Eventos que deberías marcar en la gráfica

Pon iconos o anotaciones en la línea:

Marcador 1: “Primer bonus: Luck of the Bandit (80x)”

Marcador 2: “Upgrade a All That Glitters (200x)”

Marcador 3: “Treasure at the End of the Rainbow (600x)”

De ese modo explicas visualmente:

Cómo los bonus no solo enderezan la sesión, sino que cambian la pendiente de la curva.

Por qué la gente siente que “el juego siempre puede recuperar”.

5.3. Cómo justificar que la gráfica es “para producción”

Si quieres vestirlo como análisis serio, mete bullets como:

“Simulación conceptual basada en un slot de RTP 96,34 %, volatilidad media y hit rate 32,47 %.” 
GamesHub

“Las curvas representan sesiones posibles, no garantizadas. En slots, la dispersión real sobre el RTP teórico es brutal a corto plazo.”

Eso te blinda frente a la típica acusación de “eso está manipulado”.

              continue;
            }
            if (grid[rr][cc].symbolIndex !== symbolIndex) continue;

            visited[rr][cc] = true;
            cells.push([rr, cc]);

            for (const [dr, dc] of directions) {
              stack.push([rr + dr, cc + dc]);
            }
          }

          if (cells.length >= 4) {
            clusters.push({
              symbolIndex,
              cells
            });
          }
        }
      }

      return clusters;
    }

    function computePayout(clusters, bet) {
      let total = 0;
      for (const cluster of clusters) {
        const symbol = SYMBOLS[cluster.symbolIndex];
        // Pseudomatemática simple:
        // tamaño cluster * apuesta * (baseMultiplier + pequeño random)
        const size = cluster.cells.length;
        const randBoost = 0.2 + Math.random() * 0.8;
        const multiplier = symbol.baseMultiplier + randBoost;
        const win = Math.round(size * bet * multiplier);
        total += win;
      }
      return total;
    }

    function highlightClusters(clusters) {
      for (const cluster of clusters) {
        for (const [r, c] of cluster.cells) {
          grid[r][c].element.classList.add("win");
        }
      }
    }

    // -----------------------------
    // SPIN
    // -----------------------------

    async function handleSpin() {
      const bet = Number(betInput.value) || 0;

      if (bet <= 0) {
        setStatus("Configura una apuesta válida.");
        log("Apuesta inválida.", "system");
        return;
      }

      if (bet > balance) {
        setStatus("Saldo insuficiente para esa apuesta.");
        log("Intento de apuesta sin saldo suficiente.", "system");
        return;
      }

      setSpinEnabled(false);
      setStatus("Girando...");
      log(`Apuesta de ${formatCurrency(bet)}.`, "loss");

      // Cobrar apuesta
      balance -= bet;
      updateBalanceDisplay();

      // Animación rápida antes de fijar símbolos
      for (let i = 0; i < 6; i++) {
        fillGridRandom();
        await new Promise((resolve) => setTimeout(resolve, 70));
      }

      // Grid final y cálculo
      fillGridRandom();
      const clusters = findClusters();
      const payout = computePayout(clusters, bet);

      if (clusters.length > 0) {
        highlightClusters(clusters);
      }

      if (payout > 0) {
        balance += payout;
        updateBalanceDisplay();
        setStatus(
          `Premio: ${formatCurrency(payout)} (clusters: ${clusters.length}).`
        );
        log(
          `Premio de ${formatCurrency(
            payout
          )} en ${clusters.length} cluster(s).`,
          "win"
        );
      } else {
        setStatus("Sin premio en este spin.");
      }

      setSpinEnabled(true);
    }

    // -----------------------------
    // BONO AUTOMÁTICO
    // -----------------------------

    function startBonusTimer() {
      setInterval(() => {
        countdown--;
        if (countdown <= 0) {
          countdown = COUNTDOWN_SECONDS;
          balance += BONUS_AMOUNT;
          updateBalanceDisplay();
          countdownElement.textContent = `Próximo bono: ${countdown} s`;
          log(
            `Bono automático acreditado: ${formatCurrency(BONUS_AMOUNT)}.`,
            "system"
          );
        } else {
          countdownElement.textContent = `Próximo bono: ${countdown} s`;
        }
      }, 1000);
    }

    // -----------------------------
    // INIT
    // -----------------------------

    function init() {
      createEmptyGrid();
      fillGridRandom();
      updateBalanceDisplay();
      setSpinEnabled(true);
      setStatus("Listo. Configura apuesta y pulsa SPIN.");
      log("Sesión iniciada. Prototipo en ejecución.", "system");
      startBonusTimer();
    }

    spinButton.addEventListener("click", () => {
      if (spinButton.disabled) return;
      handleSpin();
    });

    init();
  </script>
